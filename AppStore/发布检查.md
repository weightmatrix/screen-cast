# App Store 首发检查（草稿，尚未提交审核）

版本：1.4（53）。原生平台：macOS 14+、iPadOS 15+；手机使用网页接收。应用名称：李知本·投屏管理；副标题：Mac与iPad投屏，支持网页接收和本地录课。类别：效率。

## 已准备

- App Store Connect 已创建同一应用的 iOS/macOS 记录，Apple ID 6830698159，SKU touping-universal。
- 显式标识 Han.touping 与 Han.touping.broadcast 已登记。
- 中国大陆基准买断价已选择 ¥29.90，其余地区由 Apple 换算；未设涨价计划。供应国家/地区尚未确定。
- iOS/macOS 1.4 中文描述、关键词、支持网址及英文审核操作说明已保存；无需应用账户登录。两端设为手动发布，产品截图仍待补齐。
- 原生 App 添加隐私入口及清单。Mac 启用 App Sandbox、网络访问及用户选定文件夹读写；iPad 改为已声明固定类型的 Bonjour，避免依赖受限原始广播。
- 隐私政策：https://zhibenwang.com/touping/privacy.html；支持：https://zhibenwang.com/touping/support.html。页面位于服务器沙盒 app/Web，腾讯仅重建投屏容器，两页 HTTP 200。
- Mac/iPad Release Archive 成功，自动分发签名导出成功；本机归档、安装包、分发日志不入 Git。初次导出后补充录课磁盘剩余空间的必要理由清单并重新归档，上传使用更新后的归档。
- Bonjour 合成发现/解析检查通过；相同检查在签名 Mac 沙盒 fixture 内通过。服务器新增静态页面路由定向检查通过。
- 两平台53构建均已上传成功。Mac已处理并关联到1.4草稿，显示缺少出口合规证明；iPad上传成功后等待Apple处理及关联。第三方WebRTC缺少dSYM的警告未阻止上传，影响相关崩溃符号化；不能伪造符号文件。
- iPad首次上传被RPBroadcastProcessMode位置校验拒绝；按WebRTC官方示例在NSExtension直接声明SampleBuffer，保留旧Attributes供兼容，重新归档后上传成功，不修改媒体处理逻辑。
- 隐私政策URL及三类隐私标签已保存草稿：设备ID、性能数据、其他诊断数据，均用于App功能、与设备关联、不用于跟踪；尚未点击隐私标签“发布”。

## 提交前仍需完成

- 用户检查后才可最终提交审核；目前没有点击“添加以供审核”或提交审核。
- 用户表示尚无 App ICP 备案信息，不能用网站备案号替代；中国大陆销售可用性待完成备案及 Apple 核验后确定。审核联系姓名、电话、邮箱与版权主体尚待提供。
- 检查付费应用协议、收款及税务状态；涉及协议签署由用户确认。欧盟交易商资料需账户持有人核验。
- 年龄分级、内容版权声明及加密出口问卷尚待完成；隐私标签待用户复核后发布。WebRTC 含独立加密实现，不能直接声明“只使用 Apple 系统加密”或未使用加密。
- iPad服务端处理状态及最终构建关联需确认；两端上传成功不表示已上架。
- 完成 Mac 与 iPad 真机沙盒回归：双方发送/接收、横竖屏、网页、换网重连、用户选定文件夹授权及重启后录课。当前测试不代替上述实测，现有已安装 52 版未替换。
- 准备不含私人内容的真实产品截图；补齐两平台元数据，核对隐私政策与商店标签一致。不得承诺所有 NAT 都能穿透、网盘上传或触控功能。

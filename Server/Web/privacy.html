更新日期：2026年11月5日。适用于 Mac、iPad 原生应用及网页接收端。联系：weightmatrix09@163.com。

投屏内容与权限

画面和声音通过设备之间的 WebRTC 加密连接直接传输。我们的服务器不提供视频中继，不接收或保存投屏画面、声音或录课文件。屏幕共享由用户主动开始；iPad 使用系统广播确认，Mac 使用系统屏幕录制授权。请只向你信任的接收者分享地址和匹配码。接收者可以看到共享内容，也可能自行录制。

本地网络权限用于发现和连接同一网络内设备。网页不申请摄像头；仅在你主动开启共用麦克风或麦克风测试时申请音频权限。麦克风默认关闭，测试本身只显示本机音量；若你已经开启发送，测试不会额外关闭发送。Mac 的可选本地录课由接收者开启，MP4 保存到其选择的文件夹，不自动上传网盘。

共用语音与文字聊天

接收者主动开启麦克风后，声音通过加密WebRTC音轨到达投送设备，由投送设备混音转送给同一主控下其他已批准的接收者；投送者也能听见。每位接收者可关闭自己的麦克风，主控可关闭接收方语音。我们不通过服务器转发、录制或分析这些语音。系统或浏览器未提供的声音设备选择不会被绕过。

昵称由本人填写或自动分配，不是真实身份认证。文字通过有界的设备间加密DataChannel传输，投送设备在其所有投屏任务间分发；服务器不转发聊天，不把昵称、消息或语音正文写入连接审计。App仅在内存保留最近200条聊天，网页关闭连接后清空；iPad广播扩展通过现有共享钥匙串向主App短暂同步最近40条，正常结束广播清空，异常退出残留在下次广播覆盖。昵称、聊天位置、透明度及设备选择可保存在本机。主动录课或共享整个桌面时，聊天画面及可听声音可能被参与者记录，请事先告知参与者。

连接密码与申请

邀请链接仅包含投屏定位编号，不包含连接密码。接收者须填写密码及1至200字申请文字；验证通过后，投送者可查看申请文字和连接来源IP并决定是否接受。IP可能属于代理、VPN或共享出口，并非身份凭证。密码通过随机挑战验证，不作为明文协议信息发送；配对服务仅在登记期间于内存保存本次密码验证值。申请正文仅用于接入审批，不写入长期服务器审计；申请结束时清理待批记录；iPad通过共享钥匙串短暂传递待批队列，正常结束广播会清空，异常退出的残留在下次广播覆盖。请勿在申请中填写身份证件、账号密码或其他无关敏感信息。局域网HTTP网页仅适用于可信网络，不能防止局域网中的主动页面篡改。

公网连接记录

为完成配对、排查故障和处理滥用，公网服务记录连接时间、来源公网 IP、随机安装标识、设备型号、系统及应用版本、连接角色、路线和连接状态。网页使用浏览器本地存储中的随机标识；该标识不是硬件 MAC 地址。服务不采集硬件 MAC 地址。审批结果由配对服务记录；媒体连接状态及持续时长由客户端报告，可能因断网、退出或客户端误报而缺失或不准确，不代表服务器独立核验。公网 IP 直连的审批发生在投送设备上，服务器无法独立观察。来源 IP 不等于真实身份。

公网匹配码以摘要用于配对；交换的连接协商信息可能含网络地址，仅用于建立直连，不作为审计内容保存。公网 IP 直连也会向审计服务报告有限连接信息。局域网直连本身无需公网配对，但启用公网匹配等待或打开公网网页会产生相应服务请求。网页托管及网络基础设施也会处理访问所需的地址信息。

使用、保留与保护

这些信息仅用于应用功能、安全与故障处理，不用于广告、跨应用跟踪或出售。记录仅保存在我们管理的中国境内腾讯云服务器；已停用境外审计复制，不再向境外备份新增连接日志。必要网络安全日志采用184天留存策略（覆盖不少于六个月），按日或容量封闭日志段；日志段到期后清理，逐条删除时间可能延后不超过一天及一次清理周期。容量不足时拒绝新增配对，不提前覆盖未到期日志。依法需要保全的特定记录按适用要求单独处理，不无限保存全部个人信息。管理查询和下载仅向经认证授权的管理员开放并记录操作；依法向有权机关提供时核验调取依据和范围。

直连建立使用 STUN 网络地址发现，包括我们管理的服务及 Cloudflare 备用服务；相关网络服务会获得完成请求所需的网络地址。不能穿透的网络可能无法连接，本应用不通过 TURN 转发媒体。

使用目的与依据

必要网络日志用于履行网络安全义务；为建立你主动请求的连接及保障安全，仅处理必要的配对与客户端状态信息。不会收集投屏内容、文件名、窗口标题、硬件 MAC、联系人或精确位置，不以接入申请代替隐私告知。公网接入前请阅读本政策；如不同意非必要的公网处理，可停止公网连接并使用局域网模式。

你的选择

无需注册账户。你可以停止投屏、断开连接、撤销系统权限、删除本地录像和浏览器站点数据。应用设置及故障诊断保存在设备上；请在主动分享诊断前检查内容。有关数据访问、更正、删除或投诉，请通过上述邮箱联系，并说明连接日期及问题；请勿发送密码、私密画面或无关身份证件。我们会核实请求及法律允许的保留要求后处理。
